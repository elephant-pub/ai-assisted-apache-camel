# Requirements: Trailhead Order Integration

Source documents: `docs/vision.md`, `docs/inputs/kickoff-notes.md`, `docs/inputs/partner-order-sample.json`,
`docs/inputs/peakmart-order-placed-sample.json`, `docs/inputs/product-catalog-api.md`,
`docs/inputs/warehouse-picklist-format.md`. Terms follow `docs/glossary.md`. Defaults taken where the sources leave a
choice open are listed as questions in `docs/open_questions.md`.

The order integration takes every Order from its Channel (Partner Orders over HTTP, Peakmart Orders from Peakmart's
order topic), runs the same Order Checks on it, completes its Order Lines from the Product Catalog, records each
Accepted Order once in the Order Database, and delivers one Pick List per Accepted Order to the Warehouse. Web shop
orders, payments, refunds, returns, stock reservation, and changing or cancelling an Accepted Order are out of scope.
