# Partner Order to Order

**Source:** [partner-order](../partner-order.schema.json)
**Target:** [order](../order.schema.json)

| Source | Target | Rule |
|--------|--------|------|
| `orderId` | `orderNumber` | Copied; the format `TG-` and four or more digits is an Order Check (UC-003 BR-002) |
| — | `channel` | Constant `partner` |
| `partnerId` | `partnerId` | Copied after it was matched to the Partner of the API Key (UC-001 BR-002) |
| `orderedAt` | `orderedAt` | Copied with its offset |
| — | `receivedAt` | Set by the integration when the request arrives, in UTC (UC-001 step 4) |
| — | `correlationId` | Generated by the integration when the request arrives (NFR-013) |
| `customerEmail` | `customerEmail` | Copied when present |
| `shipTo.name` | `shippingAddress.recipientName` | Copied; missing or empty is a Rejection Reason (UC-003 BR-007) |
| `shipTo.street` | `shippingAddress.streetLine` | Copied; missing or empty is a Rejection Reason (UC-003 BR-007) |
| `shipTo.city` | `shippingAddress.city` | Copied; missing or empty is a Rejection Reason (UC-003 BR-007) |
| `shipTo.postalCode` | `shippingAddress.postalCode` | Copied; missing or empty is a Rejection Reason (UC-003 BR-007) |
| `shipTo.country` | `shippingAddress.country` | Copied; anything but `US` or `CA` is a Rejection Reason (UC-003 BR-008) |
| — | `shippingAddress.stateRegion` | Not set: the Partner Order has no state |
| `lines` | `lines` | One Order Line per line, in the order the Partner sent them; fewer than 1 or more than 30 is a Rejection Reason (UC-003 BR-005) |
| — | `lines[].lineNumber` | Calculated: the position of the line in `lines`, from 1 |
| `lines[].sku` | `lines[].sku` | Copied; checked against the Product Catalog (UC-003 BR-009) |
| `lines[].quantity` | `lines[].quantity` | Copied; outside 1 to 20 is a Rejection Reason (UC-003 BR-006) |
| — | `lines[].unitPrice.amount` | Lookup: `listPrice` of the Product from the Product Catalog, `GET /products/{sku}` (UC-003 step 9), written with two decimals; the Catalog Price (UC-001 BR-006) |
| — | `lines[].unitPrice.currency` | Constant `USD` (C-020) |
| `lines[].unitPrice` | — | Dropped: the Catalog Price applies, not the Partner's price (UC-001 BR-006) |
| — | `lines[].productName` | Lookup: `name` of the Product from the Product Catalog (UC-003 step 9) |
| — | `lines[].unitWeightGrams` | Lookup: `weightGrams` of the Product from the Product Catalog (UC-003 step 9) |
