# Peakmart Order Event order.placed to Order

**Source:** [peakmart-order-placed](../peakmart-order-placed.schema.json)
**Target:** [order](../order.schema.json)

| Source | Target | Rule |
|--------|--------|------|
| `order_ref` | `orderNumber` | Copied; the format `PM-` and digits is an Order Check (UC-003 BR-002); an Order Number already received makes the Order a Duplicate (UC-002 BR-002) |
| — | `channel` | Constant `peakmart` |
| `event_id` | `eventId` | Copied |
| `event_type` | — | Dropped: only `order.placed` reaches the mapping; other types are skipped (UC-002 BR-001) |
| `occurred_at` | `orderedAt` | Copied with its offset; taken as the time the Customer placed the Order (UC-002 BR-008) |
| — | `receivedAt` | Set by the integration when it reads the Order Event, in UTC (UC-002 step 3) |
| — | `correlationId` | Generated by the integration when it reads the Order Event (NFR-013) |
| `buyer.email` | `customerEmail` | Copied when present |
| `ship_to.full_name` | `shippingAddress.recipientName` | Copied; missing or empty is a Rejection Reason (UC-003 BR-007) |
| `ship_to.address1`, `ship_to.address2` | `shippingAddress.streetLine` | Joined by ", "; `address2` only when present and not empty (UC-002 BR-007); missing or empty is a Rejection Reason (UC-003 BR-007) |
| `ship_to.city` | `shippingAddress.city` | Copied; missing or empty is a Rejection Reason (UC-003 BR-007) |
| `ship_to.state` | `shippingAddress.stateRegion` | Copied when present (UC-002 BR-007) |
| `ship_to.zip` | `shippingAddress.postalCode` | Copied; missing or empty is a Rejection Reason (UC-003 BR-007) |
| `ship_to.country_code` | `shippingAddress.country` | Copied; anything but `US` or `CA` is a Rejection Reason (UC-003 BR-008) |
| `items` | `lines` | One Order Line per item, in the order Peakmart sent them; fewer than 1 or more than 30 is a Rejection Reason (UC-003 BR-005) |
| — | `lines[].lineNumber` | Calculated: the position of the item in `items`, from 1 |
| `items[].sku` | `lines[].sku` | Copied; checked against the Product Catalog (UC-003 BR-009) |
| `items[].qty` | `lines[].quantity` | Copied; outside 1 to 20 is a Rejection Reason (UC-003 BR-006) |
| `items[].price_usd` | `lines[].unitPrice.amount` | Copied; the Peakmart Price (UC-002 BR-003); the Catalog Price the Product Catalog answers is not used |
| — | `lines[].unitPrice.currency` | Constant `USD`: Peakmart prices are in US dollars (C-006) |
| — | `lines[].productName` | Lookup: `name` of the Product from the Product Catalog, `GET /products/{sku}` (UC-003 step 9) |
| — | `lines[].unitWeightGrams` | Lookup: `weightGrams` of the Product from the Product Catalog (UC-003 step 9) |
